## サイズ変化の基本仕様を理解する

この脱出系 Obby の最大の特徴は、開発者の YTPACKSTABBER 氏と Tweakified 氏によって構築されたトグル式の変身エンジンです。アバターの寸法を変更してもステータスが受動的に強化されるわけではなく、物理演算プロファイル、当たり判定（ヒットボックス）、ジャンプのクリアランス、そして慣性モーメントに直接影響を及ぼします。

安定して攻略を進めるには、各形態がゲームエンジン内で移動ルールをどのように変化させるかを記憶しておく必要があります。

| 形態ステート | ヒットボックス特性 | 移動速度 | ジャンプ力 / 頭上クリアランス | 主な戦術的役割 |
| :--- | :--- | :--- | :--- | :--- |
| **縮小（ミニ）** | 標準体積の約25% | 中程度（俊敏性が高い） | 垂直方向は低め、水平方向は標準 | パイプ、通気口、レーザー格子、狭い隙間への潜り込み |
| **標準（ベース）** | 標準体積の100% | 基準速度 | 基準ジャンプ力 | 通常の足場移動、標準的な階段登り、基本チェックポイント |
| **巨大化（ジャイアント）** | 標準体積の約250%以上 | 慣性が重い | 垂直の段差超えが高い、歩幅が極大 | 広い隙間の横断、高所の足場への到達、重圧感知プレートの作動 |

### 物理演算と衝突判定の細かな挙動

空中での形態切り替えは、ゲーム内で最も重要なテクニックの1つです。ジャンプ中に「縮小」から「巨大化」へと移行すると、前進の慣性を維持したまま高度を稼ぐことができ、遠くの足場へ届く距離を効果的に伸ばせます。逆に、ジャンプの頂点で「縮小」すると、回転ノコギリや帯電ワイヤーといった頭上のトラップの下へ瞬時に潜り込むことができます。

ゲームエンジンの基礎やコミュニティによるパッチ更新の状況は、[Roblox 公式プラットフォーム](https://www.roblox.com) で直接確認でき、物理演算の調整がジャンプのメカニクスにどう影響しているかを追跡できます。

### 序盤ステージ（1–5）の要点

レベル1から5では、**Army Escape Army Growth** の基本的なサイクルを学びます。プレイヤーは隔離施設の中からスタートし、独房のドアには下部に狭い隙間があります。体を縮小させることで、鉄格子の下を這って進むことができます。その直後には高い壁のバリケードが出現し、縮小状態のままでは立ち往生してしまいます。ここでは巨大化して歩幅を広げ、足場となるオブジェクトを使わずにコンクリートの仕切りを直接またぎ越す必要があります。

### 中盤の難関：下水道とセキュリティ（レベル 6–15）

下水道セクションでは環境トラップである液体が登場します。有毒廃棄物のプールに触れると、アバターは即座にミスとなります。このステージでは以下の点に注意してください：
- ミニ形態を維持することで、下水トンネル内を滑り抜けるのに十分な低さを保てます。
- 浮遊するパイプを飛び移るには、標準形態が必要になります。
- 狭いトンネル内で巨大化に切り替えると、天井との頭部衝突によるノックバックが発生し、即死ゾーンへ弾き飛ばされるペナルティを受けやすくなります。

## サイズ状態ごとの特徴・戦略比較

適切な瞬間に正しい変身を実行するには、それぞれの体格のメリットとデメリットを理解しておく必要があります。1つの形態だけに頼りすぎることが、後半ステージで脱落する最も一般的な原因です。

| 項目 | 縮小状態（小） | 巨大化状態（大） |
| :--- | :--- | :--- |
| **被弾・衝突リスク** | 極めて低い。高い位置の投射物を容易に回避 | 高い。表面積が広いためトラップに引っかかりやすい |
| **狭い足場での安定性** | 精度が高く、端からの滑落が最小限 | 精度が低い。足のクリッピングにより不意に落下しやすい |
| **水平方向の隙間越え** | 苦手。リーチが短いため中間の足場を細かく経由する必要あり | 圧倒的。巨大な歩幅で中間の足場をスキップ可能 |
| **カメラの視界** | 周囲の地形を見渡せるクリアな周辺視野 | キャラクターモデルが大きいため近接アングルが遮られる |
| **感圧プレートの起動** | 軍用ヘビースイッチを押すには重量不足 | 工業用の床面トリガーを一瞬で押し下げ可能 |

## よくあるトラップと障害物の突破法

21のステージを通じて、特定の障害物が難易度を上げながら繰り返し登場します。対抗策を事前に身につけておくことで、スピードランのタイムを短縮し、無駄なミスを防ぐことができます。

### レーザートリップワイヤーとモーションスキャナー

レーザーグリッドには、静止ビームと移動スキャンの2パターンがあります。これらのトラップに遭遇した際は：
1. **レーザーの高さを確認する:** 低いビームは巨大化して飛び越え、胸の高さのビームは縮小して下を潜り抜けます。
2. **交互に並ぶ二重レーザーへの対処:** 最初のビームの下を縮小して潜り、2歩ダッシュしたら即座に標準サイズへ切り替えて後続の低いフロアビームをジャンプで越えます。
3. **無駄なトグル連打を避ける:** サイズ変更キーを連打しすぎるとキャラクターモデルの同期ズレが発生し、レーザーの当たり判定の内側に挟まってしまうことがあります。

### 崩れる橋と感圧プラットフォーム

後半のレベルには、ひび割れた吊り橋が登場します。ここでの **Army Escape Army Growth** テクニックの使用には、直感とは逆の判断が求められます。

| 障害物タイプ | よくあるミス | 攻略ストラテジー |
| :--- | :--- | :--- |
| **崩れるコンクリート** | 素早く渡ろうとして巨大化する | 小さいサイズを維持して重量負荷を減らし、タイルが落ちる前に素早く渡る |
| **スプリング式ピストン** | 小さい形態で高く飛ぼうとする | 巨大化してピストンに乗りバネをしっかり圧縮させた後、射出中に空中で縮小する |
| **出没する壁のトゲ** | 標準サイズのまま強行突破する | 完全に縮小し、外側の縁石にぴったり張り付いて進む |
| **高セキュリティゲート** | バイパスキーを探し回る | 最大サイズまで巨大化して外周フェンスを乗り越え、着地時に縮小する |

## スピードラン向け上級パルクールテクニック

クリアタイムを極限まで縮めたいプレイヤーにとって、移動アクションの最適化は必須です。トップクラスのスピードランナーは、サイズ変更時にも決して足を止めません。

```
障害物に接近 -> ジャンプ始動 -> 空中でサイズ切り替え -> 着地点にヒット -> 即座に慣性をリセット
```

### プロレベルの値千金テクニック

- **ストライドキャンセル:** 巨大化状態で広大な隙間を跳び越える際、着地の直前にミニ形態へ切り替えます。これにより前方向への滑り慣性が打ち消され、足場から滑り落ちることなく小さなプラットフォームにピタッと着地できます。
- **ベントホッピング:** 通気口セクションでは、ミニ形態を維持したまま連続でバニーホップを行います。天井が低いため、ジャンプ時に小さなモデルが天井に引っかかってわずかに前方へ押し出され、わずかな加速効果が得られます。
- **カメラアングルの調整:** 狭い梁の上を進む際は、三人称視点のカメラを常に真上（トップダウン）に向けてください。巨大化しているとアバターの肩で前方の視界が遮られるため、正確な足の置き場を把握するには真上からの視点が不可欠です。
- **入力の先行バッファ:** 狭い隙間に突入する際は、約0.2秒手前でサイズ変更を入力してください。変身が遅すぎると、外側のヒットボックスが枠に接触してしまい、即座にリセット扱いになります。

**Army Escape Army Growth** のメカニクスを極めることで、過酷な障害物を難なく突破し、施設の全21ステージをあっという間に駆け抜けることができるようになります。

## よくある質問（FAQ）

### このサイズ変化ミリタリーObbyの主な目的は何ですか？
全21ステージで構成された厳重な軍事研究施設から脱出することが主な目的です。ダイナミックなサイズ変更を駆使して、狭い隙間を這い進んだり、高所の足場へ跳び移ったり、危険な環境トラップを回避したりしながら進みます。

### Army Escape Army Growth はジャンプの挙動にどう影響しますか？
キャラクターの質量とスケールは、ジャンプのクリアランスと落下速度に直結します。巨大化形態は高い段差へのリーチと広い歩幅を提供し、縮小形態は狭いトンネルを通り抜け、空中のトラップ判定を避けるのに役立ちます。

### 変身時に壁の中に埋まってしまうのはなぜですか？
十分な空間（頭上や周囲）がない場所で巨大化に切り替えると、壁に挟まれたり圧死したりします。体を大きくする前には必ず周囲に十分なスペースがあることを確認してください。そうしないと物理演算エンジンによって圧死と判定されるか、マップ外へ弾き出されてしまいます。

### 課金ゲームパスがなくても全21レベルをクリアできますか？
はい。すべてのステージは、基本の無料サイズ変更機能だけで完全にクリアできるように設計されています。ショップで提供されているアップグレードやパスは、見た目の変更やショートカット用のアイテムであり、通常のゲーム進行はプレイヤーのタイミングとパズル解決能力のみに依存します。
