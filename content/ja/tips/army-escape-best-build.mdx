## 無敵の軍隊を構築するためのコアメカクス

効果的な戦闘集団を編成するには、移動速度、投射物の軌道、そして防御ヒットボックスがどのように影響し合うかを理解する必要があります。初心者にありがちな失敗は、支援ラインを用意せずに、重騎兵や攻城兵器といった単一の役割に特化した高コストユニットに全リソースを費やしてしまうことです。

ブレイクアウト戦略を成功させるには、主に3つの戦闘役割が重要となります：
- **アンカーユニット（前線維持）：** ダメージを吸収し、敵の一斉射撃を防ぎ、領地を安定させる頑丈な前衛や多層バリケード。
- **後衛火力（バックライン）：** 直接の近接戦闘から守られつつ、壊滅的なダメージを与える遠距離スペシャリスト。
- **ディスラプター＆フランカー（攪乱・側面強襲）：** 防御障壁を突破して攻城兵器を狩り、敵のキングに圧力をかける素早いショックユニット。

部隊全体の移動速度を調整することで、各個撃破されるキルゾーンへと1体ずつ突入することなく、まとまった戦線として進軍できます。コミュニティの戦略体験でユニットの動きやタイミングを直接試してみたい場合は、[Roblox プラットフォーム](https://www.roblox.com/)をチェックしてみてください。

| **戦列歩兵 (Line Infantry)** | 前線への圧力 | 建造物破壊、キング狩り、終盤のコストパフォーマンス | 槍兵、重戦獣 |
| **槍兵 (Spearmen / Pikes)** | 対騎兵の壁 | 騎兵突撃の阻止、安価な前線防御 | 遠距離投射物の一斉射撃 |
| **攻城兵器 (Siege Engines)** | 範囲攻撃による破壊 | 高いスプラッシュダメージ、密集した歩兵や軍船の一撃撃破 | 足の速い小競り合いユニット、フランカー |
| **軽騎兵 (Light Cavalry)** | 攪乱＆斬首作戦 | 混乱を引き起こす機動力、キングの移動強制、攻城兵器キラー | 防衛タワー、長柄武器 |
| **重装騎兵 (Heavy Armored Cav)** | 突入・突破 | 高い投射物防御力、後衛の突破 | 高リソースコスト、槍兵 |

## トップ3ロードアウト：Army Escape 最強ビルドを見出す

マップや対戦相手のラインナップが異なれば、求められるユニットパッケージも変わります。プレイヤーの膨大な経験とトップコミュニティの報告に基づき、常に勝利をもたらす実績のある3つの主要ビルドを紹介します。

```
前線アンカー（壁 / 槍兵） ➔ 中衛火力（カタパルト / クロスボウ） ➔ 側面迎撃（ラクダ / アサシン）
```

### 1. シージ・ブレイクアウト（重砲撃プッシュ）

この構成は、強固に要塞化された静的ラインを突破するための **Army Escape 最強ビルド** として広く認識されています。防護壁、対騎兵スクリーン、そして長距離攻城兵器の王道的な相互作用を活かしたビルドです。

```
[多層壁] ➔ [前進する槍兵] ➔ [頭上から砲撃するカタパルト]
```

- **槍兵：** 突入してくる騎兵の突撃を受け止め、バリケードを敵陣へと物理的に押し上げます。
- **カタパルト：** 壁の後方から密集した防衛隊、軍船、防衛拠点を粉砕します。
- **多層壁：** 2重の壁が投射攻撃を吸収しつつ、攻城兵器は障害なくその頭上から安全に射撃できます。

### 2. ラピッド・ショック・ブリッツ（高速奇襲）

相手が高価な終盤ユニットや移動の遅い砲兵に依存している場合、このセットアップは圧倒的なスピードと突然の攪乱に焦点を当てます。

```
[スカウトの嫌がらせ] ➔ [高速ラクダ＆ナイト] ➔ [騎射手]
```

- **スカウト：** 最初に送り込み、敵の弾薬を消費させ、防衛の経路探索を乱します。
- **ラクダ＆ナイト：** 魚雷のように機能し、隙間をすり抜けて遠距離ユニットを暗殺し、拠点を突破します。
- **騎射手：** 近接戦を避けながら機動支援射撃を行い、敵歩兵を徐々に削り取ります。

### 3. ディフェンシブ・アトリション・バンカー（防衛消耗戦バンカー）

狭いチョークポイントがある複合マップ向けに設計されたこのロードアウトは、敵の突撃を多大な損失に終わらせることで、相手のリソースを枯渇させます。

```
[ダブル要塞 / ボンバードタワー] ➔ [強化壁] ➔ [スリンガー＆修道士]
```

- **ボンバード / バリスタタワー：** 外周に接近する重量級ターゲットを排除します。
- **スリンガー：** 防衛建造物の背後からノックダウンを伴う放物線攻撃を放ち、近接プッシュを妨害します。
- **ウォーモンク：** 地形の窪みに配置し、スカウトや軽襲撃部隊に対して百発百中の正確無比な射撃を浴びせます。

## 段階ごとの戦術的展開

**Army Escape 最強ビルド**を実行するには、試合のフェーズに合わせた正確なタイミング管理が必要です。高ティアユニットを焦って早期に配備すると、破産して迅速なカウンター攻撃に晒される原因になります。

```
フェーズ1：偵察＆要塞化 ➔ フェーズ2：槍兵/壁ライン形成 ➔ フェーズ3：攻城兵器配備 ➔ フェーズ4：キング狩り
```

### フェーズ1：序盤の偵察と外周セットアップ
まずはスカウトを1体マップの向こうへ送り出します。これにより敵に早期のリソース投入を強要し、選択した文明戦略を暴き、本拠地から砲火をそらすことができます。隣接する壁は2枚以上連続して横に建てないようにしてください。幅広くバリケードを張るよりも、奥行きを持たせて重ねる方が遥かに効果的です。

### フェーズ2：中盤の戦線安定化
前線アンカーを配備します。敵の厩舎や騎兵ユニットを確認した場合は、即座に槍兵を投入してください。敵が大量の遠距離射撃から入ってきた場合は、高台に重装アーマーユニットや基本的な防衛タワーを配置します。この移行期に無理をして高級なナイトを買い過ぎないように注意してください。

### フェーズ3：攻城兵器の組み立て
前線の壁がしっかりと持ちこたえたら、その安全な背後にカタパルトや砲撃船を配置します。タワーや味方の砲兵は自陣の壁越しに問題なく射撃できるため、敵は開けた土地を前進せざるを得ず、集中したスプラッシュダメージの餌食になります。

### フェーズ4：斬首ストライク
砲撃によって敵の前線が崩壊した瞬間、キング狩りの奇襲部隊を投入します。アサシンや俊敏な軽騎兵は、残存する防衛建造物をすり抜け、敵指揮官が態勢を立て直す前に確実に排除を完了できます。

| 試合段階 | 目標リソース配分 | 主な配備目標 | 避けるべき重大なミス |
| :--- | :--- | :--- | :--- |
| **序盤 (0〜2分)** | 防衛80%、偵察20% | 壁の多層化、単独スカウトの投入 | バックアップなしで高価なナイトを乱発する |
| **中盤 (2〜5分)** | 前線50%、火力50% | 前進する槍兵スクリーンの背後に攻城兵器を配置 | 壁を横一列に過剰配置する |
| **終盤 (5分以降)** | プッシュ40%、斬首60% | 敵基地へ歩兵を進軍、アサシン投入 | 後衛の砲兵の位置調整を忘れる |

## ユニットの相性と直接カウンター戦略

どのような作戦であっても、敵と接触した後の臨機応変な調整なしに成功し続けることはできません。**Army Escape 最強ビルド**を使いこなすには、敵の対抗手を素早く見極め、即座に控えユニットをローテーションさせる必要があります。

コミュニティのデータが示す通り、接戦の勝敗を分けるのはユニットのコストパフォーマンスです。高額なゴールドを注ぎ込んだエリートユニットが、安価なカウンターユニットに簡単に排除されてしまうと、あっという間に圧倒的な不利に追い込まれます。

| 脅威ユニット | 主な脅威要素 | ハードカウンターの選択 | 実践のコツ |
| :--- | :--- | :--- | :--- |
| **戦象 (War Elephant)** | 壊滅的な近接ダメージ＆威圧オーラ | カタパルト、アサシン、槍兵 | 攻撃する前に自陣深くへ誘い込む |
| **カタパルト / 砲兵** | 長距離からの建造物および部隊の一掃 | 高速スカウト、ラクダ、アサシン | 大きく側面へ回り込む。直線的な突撃は避ける |
| **ナイトラッシュ** | 貫通突撃と高い対投射物装甲 | 深みを持たせた槍兵陣形 | 密集した槍兵の群れにナイトを強制交戦させる |
| **歩兵の群れ** | 絶え間ないプッシュ力と壁破壊性能 | スリンガー、カタパルト、ウォーモンク | ノックダウンやノックバックを使って陣形の結束を崩す |
| **軍船艦隊** | 強力な沿岸防衛と高耐久力 | アサシン、キャノン船 | 自軍の水域に進入してきた船にステルスユニットを送り込む |

### 特殊な脅威への対策
- **ラクダへの対策：** ラクダは無防備な後衛を排除するために設計された高速魚雷のように動きます。遠距離スペシャリストのはるか前方ではなく、すぐ隣に槍兵を配置してください。
- **ウォーモンクへの対策：** モンクは地形のくぼみを利用し、攻撃を外さないため、耐久力の低いスカウトにとって極めて危険です。カタパルトのスプラッシュダメージやスリンガーのノックダウン攻撃で炙り出しましょう。
- **アサシンへの対策：** アサシンは高価値の標的や指揮官を直接狙ってきます。安価な戦列歩兵や捨て駒のスカウトで進路を塞ぎ（ボディブロック）、主要ユニットから初撃を逸らしてください。

## 高度な地形および要塞化戦術

地形の配置は、ビルドがどれほど効果的に機能するかを大きく左右します。熟練のプレイヤーは、マップのレイアウトや高低差のアドバンテージに応じて防衛陣形を変化させます。

```
[高台のタワー] ➔ [谷のチョークポイント：二重壁] ➔ [砲撃キルゾーン]
```

### 要塞多層化のルール
1. **横並びの壁の乱立を避ける：** 3〜4枚の壁を横一列に並べて配置するのは、貴重なスペースとリソースの浪費です。代わりに、多層構造の内門を作成してください。最初のバリケードが破られても、攻城兵器は2枚目の壁の背後で安全を維持できます。
2. **高台の要塞配置：** 静的な監視タワーやボンバードタワーは、必ず高台の地形に配置してください。これにより通常の歩兵から簡単に解体されるのを防ぎ、防衛兵器のクリアな射角を広げることができます。
3. **水陸ハイブリッドトラップ：** 川や湖のあるマップでは、軍船を矢の攻撃を吸収する「動く壁」として活用できます。座礁させた軍船のすぐ後ろにロングボウやクロスボウを配置することで、難攻不落の防衛スクリーンが完成します。

規律あるポジショニングと、本ガイドで解説した強力なユニットペアリングを組み合わせることで、自軍は確実に膠着状態を打ち破り、アグレッシブなラッシュを撃退し、すべての交戦においてペースを支配できるようになります。

## よくある質問（FAQ）

### なぜ「槍兵・カタパルト・壁」の組み合わせが Army Escape 最強ビルドなのですか？
この組み合わせはあらゆる根本的な弱点をカバーしているためです。槍兵が素早い近接フランカーを撃退し、防衛壁を前線へと押し上げます。その間、カタパルトがバリケード越しに射撃して密集した遠距離ユニットを一掃するため、安全性、継続的な進軍、そして圧倒的な火力のすべてを同時に実現できます。

### ラクダではなくナイトを配備すべきタイミングはいつですか？
ナイトは、相手に対抗ユニットを即座に生産するゴールドがない序盤や、リソースが尽きかけた終盤に真価を発揮します。一方、ラクダはより足が速くコストも安いため、敵の砲兵を狩る必要がある場合や、高速の嫌がらせユニットを迎撃する際の後出しカウンターとして最適です。

### アサシンからキングを守るにはどうすればよいですか？
アサシンはキングなどの高価値ターゲットに向かって一直線に移動します。指揮官の周囲に戦列歩兵を密集させるか、アサシンの移動経路上に槍兵を差し向けることで無力化できます。側面のルートを常に警戒し、軍が対応する前に奇襲暗殺されないよう視野を確保しておきましょう。

### 現在のメタで歩兵スパム（大量生産）は有効ですか？
歩兵スパムは、経験の浅いプレイヤーに対してや、相手のリソースが枯渇した終盤戦では非常に有効です。しかし、熟練した指揮官相手では、槍兵、戦象、またはカタパルトのスプラッシュダメージによって単一歩兵の突撃は簡単に完封されてしまいます。戦列歩兵は単独の主力軍としてではなく、プッシュを支える支援部隊として運用するのが最も効果的です。
