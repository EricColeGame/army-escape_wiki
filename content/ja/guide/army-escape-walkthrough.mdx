## フェーズ1：兵舎および仮眠室からの脱出

ミッションは居住エリアから始まります。セクター1の主な目的は、室内のドアラッチをバイパスし、中央換気ダクトネットワークにアクセスするための基本ツールを確保することです。

```
[仮眠室の隅] ──(バールを発見)──> [ロッカーエリア]
       │                                     │
       ▼                                     ▼
[マットレス下：鍵] ──(引き出しを開ける)──> [タクティカルライト]
```

### 兵舎のステップ別チェックリスト

1. **下段ベッドを調べる：** 一番左にあるマットレスをクリックします。布の端を持ち上げて**真鍮の鍵**を入手します。
2. **衣装トランクを開ける：** インベントリから**真鍮の鍵**を選択し、ベッドの足元にあるトランクを調べます。中から**大型ドライバー**と**破れた地図の破片（パート1）**を回収します。
3. **壁の換気口を調べる：** ナイトスタンドの上にある換気口グリルの四隅のネジに**大型ドライバー**を使用します。グリルを取り外して**ワイヤーカッター**を入手します。
4. **壁掛け時計の謎を解く：** 停止している兵舎の時計が指している時刻（通常は04:25）を確認します。これを4桁の数字（`0425`）に変換し、ポスターの裏に隠された壁金庫に入力します。金庫から**セキュリティキーカード（レベル1）**を入手します。

| 入手アイテム | 発見場所 | 直後の用途 | 後続セクターへの影響 |
| :--- | :--- | :--- | :--- |
| **真鍮の鍵** | ベッドのマットレス下 | 居住エリアのトランクを開ける | 基本ツールの入手 |
| **大型ドライバー** | 居住エリアのトランク | 壁の換気口グリルを外す | ダクトへの進入が可能になる |
| **ワイヤーカッター** | 換気ダクト内 | 外周の金網を切断する | フェーズ3で必須 |
| **セキュリティキーカード（L1）** | 隠し壁金庫 | 兵舎の出口ドアを解錠 | 兵器庫への通路が開く |

## フェーズ2：兵器庫と通信センター

兵器庫に入ると、単なるアイテム探しから複雑な論理パズルへとゲーム性が変化します。この**Army Escape 攻略**の段階において、コミュニティの報告によると、60％以上のプレイヤーが正しい色の配線順序が分からずメインブレーカーの作動で立ち往生しています。

### 兵器庫の武器クレート暗号

中央の武器クレートを開けるには、壁に掛けられた階級章に基づいたカラーホイールの入力が必要です。一般的な軍の階級章（二等兵のV字章から将軍の星章まで）は、以下の数値に対応しています。

*   **1本山（シェブロン）：** 赤ダイヤル = 1
*   **2本山（シェブロン）：** 緑ダイヤル = 2
*   **弧付き3本山（シェブロン）：** 黄ダイヤル = 4
*   **五芒星：** 青ダイヤル = 5

`1 - 2 - 4 - 5` の順に入力するとロックが解除され、**バーナーの持ち手**と未充電のバッテリーパックが手に入ります。

### 通信端末とヒューズボックスの調整

兵器庫の右側にある無線コンソールへ向かいます。補助電源パネル内の3つのヒューズが切れているため、モニターには断続的な砂嵐が映し出されています。

| ヒューズソケット | 必要アンペア数 | 発見場所 | 作動する機能 |
| :--- | :--- | :--- | :--- |
| **スロットA（赤）** | 15A セラミックヒューズ | 無線デスクの一番下の引き出し | レーダーディスプレイ |
| **スロットB（青）** | 20A 高耐久ヒューズ | 作業台の緩んだレンガの裏 | キーパッドバックライト＆ドアリレー |
| **スロットC（黄）**| 30A 工業用ヒューズ | 壊れたタクティカルランタンの内部 | 外周メインアラームの解除 |

3つのヒューズをすべてセットしたら、左側の壁にあるブレーカースイッチを操作します。スイッチ2を下げたまま、スイッチ1、3、4を上に上げます。通信モニターが点灯し、座標 `38°N - 77°W` が表示されます。これが兵器庫の脱出ハッチを開ける電子キーパッドのパスワード（`3877`）になります。

## フェーズ3：車両整備場と地下トンネル

兵器庫を出ると、地下の車両整備トンネルに出ます。このエリアには高圧機械やセキュリティフェンスがあり、インベントリ内のアイテム合成が求められます。

### 油圧リフトの修理

制御ブースへ続くキャットウォーク（高所通路）に到達するには、車両用機械リフトを上昇させる必要があります。

1. 作業台のタイヤの山板の横にある**空のオイル差し**を回収します。
2. 装甲兵員輸送車（APC）の近くにある燃料ドラム缶に近づき、オイル差しに作動油（油圧作動油）を満たします。
3. 車両リフトの操作盤の後ろにある錆びたギアシャフトに注油します。
4. 工具箱から回収した**鉄製ギア**を、電動ギアアセンブリに取り付けます。
5. メインレバーを引き下げます。プラットフォームが上昇し、通風孔キャットウォークへの足場が完成します。

```
[空のオイル差し] + [燃料ドラム缶] ──> [満タンのオイル差し]
       │
       ▼
[錆びたギアに注油] + [鉄製ギアを取り付け] ──> [油圧リフト起動]
```

### ガスマスクのフィルターパズル

地下の下水道パイプを通過する前に、有毒な排気ガスから身を守るための防護具を組み立てる必要があります。この手順を踏まずに進むと、画面がぼやけて車両整備場の入り口まで戻されてしまいます。

| 部品 | 配置場所 | 入手方法の詳細 |
| :--- | :--- | :--- |
| **マスクのゴム本体** | 軍用ジープの運転席 | グローブボックスのラッチをクリック |
| **活性炭フィルター** | 作業台下の薬品ロッカー | 暗証番号 `7-4-1` を入力して解錠 |
| **密閉用ガスケット** | エンジンクレーン付近の吊り下げフック | 長い鉄パイプを使って落とす |

インベントリ画面でこれら3つのアイテムを組み合わせます。組み立てたガスマスクを装備してから、トンネルの最奥にある鉄製ハッチをクリックしてください。

## フェーズ4：外周ゲートと司令監視塔

いよいよ最終外周エリアに到達しました。この最後の警戒網を突破するには、サーチライト網を無力化し、自動ゲートのモーターを作動させる必要があります。

### サーチライト網の無力化

制御ブースからは外周の電気柵が一望できます。2台の自動スポットライトがメインゲート周辺を常に監視しています。光の照射範囲に入ると警備システムが作動し、ゲートのロックが初期化されてしまいます。

サーチライトを無力化する手順：
1. 車両整備場の作業台近くで見つかる**ガスボンベ**と**バーナーの持ち手**を組み合わせ、南京錠を溶かして屋根へ続くハシゴを降ろします。
2. スポットライトの配電ボックスを開きます。配線切断パズルが始まります。
3. セクター2の通信ボードにあった配線図を参照します。最初に**黄色と白の縞模様ワイヤー**を切り、次に**青色の単色ワイヤー**を切断します。赤い通電ワイヤーには絶対に触れてはいけません。

| 防衛設備 | 初期状態 | 無力化の方法 | 必要な解除アイテム |
| :--- | :--- | :--- | :--- |
| **外周サーチライト** | 監視スキャン中 | 配電ボックスの黄・青ワイヤーを切断 | ワイヤーカッター |
| **高圧電流フェンス** | 440V通電中 | サブ変圧器を停止 | 絶縁ゴム手袋 |
| **鋼鉄製主落とし格子** | 油圧デッドボルト施錠 | 手動圧力バルブをオーバーライド | 大型パイプレンチ |
| **最終防護ゲート** | 英数字デジタルロック | 判明した最終パスキーを入力 | マスターコマンドコード |

### 最終ゲートオーバーライドの入力

フェンスへの給電を断ったら、頑丈な鋼鉄製落とし格子の端末を調べます。兵舎で手に入れた**破れた地図の破片（パート1）**と、監視塔の机の引き出しから入手した**破れた地図の破片（パート2）**を組み合わせます。

地形図のグリッドを重ね合わせることで、最終脱出コード **BRAVO-9-DELTA-4** が浮かび上がります。

端末の画面を選択し、フォネティックコードをテンキーの数字に対応させて（B=2、D=4）、`2-9-4-4` の順に入力します。重厚な鋼鉄フェンスが開き、軍事基地からの完全脱出が完了します！

## よくあるパズルのトラブルシューティング

詳細な**Army Escape 攻略手順**に従っていても、操作ミスや視覚的な見落としによって行き詰まってしまうことがあります。以下に、プレイヤーコミュニティで頻繁に報告されるトラブルと解決策をまとめました。

| 症状・行き詰まりポイント | 考えられる主な原因 | 対処法 |
| :--- | :--- | :--- |
| セクター2のキーパッドが赤く点滅してロックされる | 端末に表示された数字ではなく生の座標記号を入力している | 通信端末のモニターを確認し、度数記号などを除いた数字のみ（`3877`）を入力する |
| バーナーのノズルがガスタンクに接続できない | 真鍮製接続金具が不足している | 車両整備場の廃油受け皿の中にある真鍮コネクタワッシャーを回収する |
| キャットウォークのハシゴに届かない | 油圧が不足している | ドラム缶でオイル差しを満タンにしてからギアハウジングに注油したか確認する |
| 最終ゲート端末の画面がつかない | フェンス用バックアップ発電機のリレーが作動している | 変圧器サブボックスに戻り、3番のブレーカースイッチを落とす |

部屋ごとに隅々まで確認するアプローチをとることで、アイテムの見落としを防げます。また、インベントリ内のアイテムを詳細表示（3D拡大検査モード）で再確認することも重要です。タクティカルペンや懐中電灯などのアイテムは、先端を回して開けることで中に隠された鍵やマイクロフィルムが見つかるケースがあります。

## よくある質問（FAQ）

### インベントリ内のアイテムが合成できない場合はどうすればいいですか？
多くのミリタリー脱出ゲームでは、アイテムの合成順序が厳密に定められています。まずベースとなるアイテムを詳細表示で開き、ワッシャー、ネジ、電池などの補助パーツが揃っているか、また両方のアイテムが同じ仕掛けのパーツであるかを確認してください。

### 2枚目の地図の破片はどこで見つかりますか？
2枚目の地図の破片は、監視塔の無線デスクにある右上の引き出しに保管されています。セクター3の車両整備場にあるロッカーの留め具から落ちるマグネット式キーフォブを使用すると、このマグネットロック式引き出しを開けることができます。

### 外周フェンスのワイヤーを切るとアラームが鳴るのはなぜですか？
補助発電機からフェンスに電力が供給されたままになっているとアラームが作動します。ペンチでフェンスを切断する前に、必ず監視塔の制御ブース内にある主変圧器スイッチボードを操作して送電を遮断してください。

### この攻略情報はモバイル版（スマホ版）でも有効ですか？
はい、有効です。モバイルブラウザ、Android、iOS、PCウェブポータルなど、プレイする環境によってUIボタンや持ち物欄の配置が若干異なる場合がありますが、パズルの論理、アイテムの隠し場所、暗号の答えはすべてのバージョンで共通です。
