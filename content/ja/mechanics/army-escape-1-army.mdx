## Army Escape +1 Army のコアメカニクス

このメカニクスの本質は、「スピード」「安全性」「ユニットの増殖」のいずれを優先するかという、リアルタイムの意思決定を試す点にあります。「+1」システムは継続的な戦力補給の上に成り立っています。温存または補充されたユニットはすべて、後続の防御力、攻撃力、そして障害物の突破速度を高めるパッシブな倍率要素として機能します。

要塞化されたセクターを突破する際、障害物に接触すると一定数の人員が差し引かれます。総兵力が必要数を下回った場合、そのランは即座に終了となります。このシステムを攻略するには、目の前の兵力増加と、リスクの高いルートへの寄り道とのバランスを常に見極める必要があります。

| メカニクス要素 | 機能 | 戦略的影響 | 優先度 |
| :--- | :--- | :--- | :--- |
| **基礎生成レート** | パッシブなユニット補充ペースを決定 | 削りダメージが発生する区間での継戦能力を維持 | 中 |
| **乗数ゲート** | 規定数の兵力を加算・乗算（+1、+5、x2 など） | 中盤〜終盤のバリケード突破に必須 | 最優先 |
| **環境トラップ** | 接触時に固定値の兵力を減少 | 反射神経と正確なルート取りを試す | 高 |
| **ボス／エリートバリケード** | 破壊に一定数の兵力消費が必要 | 部隊規模を試す明確な戦力チェック | 極めて重要 |
| **脱出ビーコン** | 生き残った兵力をリソースに換算 | メタ進行（永続強化）の速度を左右 | 高 |

現実の軍事におけるレジリエンスモデルにも、まさにこれと同じ思想が見られます。[米陸軍のインタラクティブトレーニングプログラム](https://www.army.mil) などの戦術ワークショップでは、プレッシャー下における体系的な問題解決として、小さな損失が組織的崩壊へと発展する前の明確な伝達と予防的介入が重視されます。この思考をゲーム内の部隊管理に応用するなら、すべての兵士を「使い捨ての駒」ではなく「極めて重要な資産」として扱うことこそが肝要です。

## 乗数ゲートのルート選択ステップ

ゲートの選択は、ステージ進行中に最も頻繁に行う微細な意思決定です。複数レーンを駆け抜ける際、加算ボーナス（フラットな +5 など）と **army escape +1 army** の倍率ブースターのどちらを選ぶべきかは、現在の部隊規模に応じた素早い計算にかかっています。

```
接近する部隊 (N) ---> [レーン分岐点]
                           ├── レーンA: 加算 (+X)
                           └── レーンB: 乗数 (xY)
```

1. **先を見据えて早期索敵:** 画面上の自部隊を直接見つめるのではなく、画面上部3分の1に視線を置きましょう。早い段階でゲートの数値を確認することで、陣形をスムーズに合わせられます。
2. **損益分岐点を計算:** 兵力が15未満のときは、固定加算（+10、+20 など）のほうが小さな乗数よりも大きな効果を発揮します。部隊が25体を超えた後は、乗数（x1.5、x2 など）を選んだほうが確実に大軍を形成できます。
3. **欲張りな罠を避ける:** 回転ブレードなどのトラップの真裏にある高倍率ゲートは、得られる兵力以上の損失を招くことが多々あります。精密な操作に絶対の自信がない限り、安全な直線ルートでの堅実な加算を選んだ方が生存率は安定します。

| 現在の部隊規模 | 選択肢A（固定加算） | 選択肢B（乗数） | 最適な選択 | 実質増加兵力 |
| :--- | :--- | :--- | :--- | :--- |
| 5体 | +10体 | x2倍 | 選択肢A | +10 対 +5 |
| 12体 | +15体 | x2倍 | 選択肢B | +12 対 +15（僅差で選択肢Aが有利） |
| 25体 | +15体 | x2倍 | 選択肢B | +25 対 +15 |
| 60体 | +30体 | x1.5倍 | 選択肢B | +30（同値：より安全なレーンを優先） |
| 120体 | +50体 | x2倍 | 選択肢B | +120 対 +50 |

プレイヤーデータによると、中央の境界線付近で進路を迷ったプレイヤーは、分離帯に衝突して最大30%の人員を失っています。進むレーンは早めに決め、増員を確保したら、次のセクターに向けて即座に陣形を整え直しましょう。

## 部隊アップグレードとリソース配分

ステージの合間において、ステータスの強化を行わずに純粋な増員数だけで後半セクターを突破することはできません。脱出によって得た通貨を部隊の効率アップグレードへと再投資することで、序盤の脆さを克服し、**army escape +1 army** の拡大ループをより素早く加速させることが可能になります。

### 主要スタッツのアップグレード

* **行軍速度（March Velocity）:** 安全な通路での移動速度が上がり、クリア時間を短縮。ただし、スピードが速すぎると複雑なトラップ地帯での反応が難しくなる点に注意が必要です。
* **陣形密度（Formation Density）:** 部隊メンバー同士の当たり判定を密集させ、外周のユニットが壁のトゲや酸のトラップに接触して削られるのを防ぎます。
* **衝突耐性（Impact Resilience）:** 破壊可能なバリケードに激突した際の兵力減少ペナルティを軽減し、より多くの兵士を終盤まで残せるようにします。
* **初期出撃数（Base Deployment Floor）:** ステージ開始時の初期ユニット数を底上げし、戦力集めが遅れがちな最序盤を有利にスキップします。

| アップグレード名 | コスト推移 | 主な恩恵 | 推奨レベル（中盤目安） |
| :--- | :--- | :--- | :--- |
| **前線強化（Frontline Bulk）** | 指数関数的（ゴールド） | 兵士1体あたりの基礎HP +1 | レベル 8–10 |
| **進軍の号令（Rallying Cry）** | 線形（トークン） | **army escape +1 army** のパッシブ発生率増加 | レベル 12+ |
| **密集訓練（Cohesion Drill）** | 段階的（ジェム） | ランクごとに部隊の広がりを15%抑制 | ランク 3 |
| **回収プロトコル（Scavenger Protocol）** | 固定増加 | 生存者あたりの獲得通貨量アップ | レベル 15 |

プレイヤーの間では、「密集訓練」へのリソース投入が最も費用対効果が高いと実証されています。コンパクトに密集した部隊は障害物の角に引っかかりにくく、狭いチョークポイントでも頭数をしっかりと守り抜くことができます。

## 危険地帯の回避とチョークポイント戦術

障害物地帯を進む際は、部隊を固いひとつの塊ではなく、柔軟に伸縮する集合体として捉える必要があります。出現する障害物は、主に「静止型トラップ」「回転・往復型ギミック」「消耗ゲート」の3つに分類されます。

### 障害物のタイプと回避プラン

1. **固定式のスパイク＆落とし穴:** 配置は固定。外壁ギリギリを通るか、中央の隙間を的確に縫うように進みます。
2. **回転ブレード／スウィーパー:** アームの回転を追いかけるように背後から通過し、正面から突っ込まないようにタイミングを合わせます。
3. **プレスピストン:** ピストンが振り下ろされた後の上昇リセットに合わせて一気に駆け抜けます。持ち上がったピストンの下で立ち止まるのは厳禁です。

| トラップ種類 | 脅威度 | 主な配置場所 | 最適な対策 |
| :--- | :--- | :--- | :--- |
| **振り子ブレード** | 高 | レーン切り替え地点 | スイングの頂点の真後ろを追従して通過 |
| **トゲ床** | 中 | チョークポイント（狭路） | 一列縦隊などの陣形アップグレードで幅を縮小 |
| **固定砲台タレット** | 極めて高い | 長い直線通路 | 最前線のユニットを盾にして射撃を相殺 |
| **崩落する橋** | 危険 | ステージ終盤 | 最大限の前進ダッシュを維持して一気に突破 |

**army escape +1 army** による補給の流れを途切れさせないことで、避けられない細かな削りダメージを相殺し続けることができます。もしゲートを開けるために10体の兵力を犠牲にする必要がある attrition ルーム（消耗戦区画）があっても、十分な余剰戦力を維持して突入すれば、足を止めることなくランを継続可能です。

## 上級者向け進行戦略

最難関のエンドゲームステージに到達するには、ルートの最適化、正確なリスク管理、そして予備兵力の細かなコントロールが不可欠です。惜敗続きのランを確実なクリアへと導くため、以下の3つの高度な戦術を取り入れましょう。

```
ステージ開始 ---> 安全地帯の索敵 ---> 計算された犠牲 ---> 倍率の重ね掛け ---> 脱出
```

* **計算された犠牲戦略（Controlled Sacrifice）:** 一方のレーンには激しいトラップの先にエリートゲートがあり、もう一方には無傷で取れる平凡な加算ボーナスしかないという場面では、想定される損失を即座に計算します。障害物で8体を失っても、**army escape +1 army** のキャッシュから+25体得られるなら、実質利益は+17となり、安全に+5体を取るレーンよりも挑む価値があります。
* **フェザリング操作（細かいタップ入力）:** 分岐の仕切りを通過する際、方向入力を押しっぱなしにせず、細かく小刻みにタップします。これにより、後続のユニットが別々の通路に分断されて中央の壁に激突・消滅するのを防げます。
* **脱出の引き際（Extraction Timing）:** 制限時間のある脱出エリアでは、端にあるわずかな補給クレートを拾うために欲張るのは禁物です。確実に脱出を完了してメタ進行用の通貨を持ち帰ることこそが、その後のステージ攻略を劇的に楽にする永続強化へとつながります。

## よくある質問（FAQ）

### Army Escape +1 Army ステージで最も多い失敗は何ですか？
わずかな兵力増加のためにリスクの高すぎるレーンへ突っ込んでしまうことです。+20のゲートを取ろうとして15体を失えば、実質+5体の増加にとどまる上、全滅のリスクまで背負うことになります。部隊の操作性アップグレードが整うまでは、安全なルートを優先するのが鉄則です。

### 固定加算と乗数ゲートはどちらを優先すべきですか？
現在の部隊数が15〜20体未満の場合は、固定加算を優先してください。乗数ゲートは元の兵力があって初めて効果を発揮します。兵力4体のときに2倍ゲートを通っても+4体にしかなりませんが、固定+10ゲートならその倍以上の兵力が手に入ります。

### 陣形密度は生存率にどう影響しますか？
陣形密度を高めると、部隊全体の専有面積（フットプリント）が縮小します。兵士同士が密集して行軍することで、外周にいるユニットが壁のトゲや振り子ブレード、コース外の奈落に接触する事故が激減し、不要な損耗を大幅に抑えられます。

### 永続アップグレードで序盤の難所を楽に突破できますか？
はい。初期出撃数のアップグレードに手厚く投資すれば、ステージ開始直後からまとまった兵力でスタートできます。このスタートダッシュがあれば序盤のバリケードも容易に破壊でき、開始直後に出現する強力な乗数ゲートの恩恵を最大限に活かすことが可能です。
